# WorldUtils (Fabric 1.21.8)

客户端 mod：自动挖矿全循环 —— 菜单传送去矿点 → 自动下挖到设定 y → 直线前挖 → 背包满/镐子耐久不足回家 → 寻路到绑定箱子存物/换镐 → 再传送回去继续。

## 标准流程配置

```
1. 绑定箱子（可多个，同一维度）：准星对准箱子 → /miner bind
2. 设置挖矿高度：/miner sety -59
3. 录制去矿点操作（支持多级菜单）：
   /miner record mine menu     ← mod 会发送 /menu 打开菜单
   然后你手动点击菜单里的格子完成传送（几级菜单都行）
   传送成功后自动保存整个操作序列
4. 设置回家操作：
   纯指令: /miner tphome home base   （站着不动等30秒那种也支持）
   或菜单: /miner record home menu   然后点菜单
5. /miner start 开始（J 键随时启停）
```

## 运行逻辑

- 到矿点后**自动垂直下挖**到设定 y（检查脚下液体/空洞，危险即停）
- 到达 y 后沿固定方向直线挖 1×2 隧道（朝向第一次开挖时自动记录，`/miner face` 可重设）
- 前方出现水/岩浆、悬崖 → 安全停止并提示
- **背包满** → 回家 → A* 寻路到箱子1存物 → 箱子满自动换下一个绑定箱子 → 全满则停止
- **镐子剩余耐久 < 20**（`/miner durability` 可改）→ 回家把旧镐放进箱子，从箱子里拿耐久充足的新镐继续；箱子里没镐了 → 停止
- 回家指令那种"站立等待30秒"的传送：等待期间不动，最长等 60 秒，失败自动重试 3 次
- 保留物品（不存入箱子）：默认所有镐子，`/miner keep add torch` 可加

## 命令一览

| 命令 | 作用 |
|---|---|
| `/miner bind` / `unbind` / `chests` | 绑定/解绑/列出箱子（准星对准） |
| `/miner sety <y>` | 挖矿目标高度 |
| `/miner record mine <指令>` | 录制去矿点操作（指令+点菜单） |
| `/miner record home <指令>` / `/miner tphome <指令>` | 回家操作（录制 或 纯指令） |
| `/miner tpmine <指令>` | 去矿点纯指令（不用菜单时） |
| `/miner durability <n>` | 换镐耐久阈值（默认20） |
| `/miner keep add/remove/list` | 保留物品管理 |
| `/miner face` | 重设挖矿朝向为当前视角 |
| `/miner start / stop / status` | 开始/停止/状态（快捷键 J） |

## 自动种地 AutoFarm（/farm，快捷键 K）

同一个 mod 里的第二套机器人：所有已绑定小区域内的耕地循环「种植 → 浇水器加水 → 收获 → 存箱」。
支持插件种子（实际物品是 sugar 等，靠自定义显示名区分，如"蚕豆种子"）。

### 配置流程

```
1. 划小区域：准星对两个角分别执行 /farm pos1、/farm pos2 → /farm zone add 蚕豆
2. 对每种作物的小区域重复上一步；不再需要设置大区域，所有小区域的并集就是扫描范围
3. 定义作物种子：手持"蚕豆种子"（实际是 sugar）→ /farm crop add 蚕豆
   （自动记录物品 id + 显示名，按名字子串匹配）
4. 绑定箱子：
   /farm bindseed 蚕豆   ← 准星对准蚕豆种子箱（每种作物一个）
   /farm bindcrop        ← 作物存放箱（可多个，满了自动换）
5. 浇水（可选）：
   手持插件洒水壶 → /farm bindcan
   /farm bindwaterer     ← 准星对准悬浮虚拟浇水器（可多个）
   /farm bindwater       ← 准星对准水面（洒水壶装水点）
   /farm interval 20 设间隔（默认 20 分钟）
6. 食物（建议绑定，保证疾跑）：
   手持要吃的食物 → /farm bindfood
   准星对准食物箱 → /farm bindfoodchest
7. 成熟判定（插件作物不是原版，需要教一次）：
   对准一株成熟作物 → /farm learn 蚕豆
   不确定哪个阶段算成熟？对作物执行 /farm info，把输出（也存在
   config/autofarm-info.log）发给开发者分析
8. /farm start 开始（K 键随时启停）
```

### 运行逻辑

- 优先级：维持饱食 > 浇水到点 > 背包快满存物 > 按 zone 补种 > 按 zone 收获并拾取 > 其他缺种补货
- A* 寻路采用按剩余角度减速的平滑转向和轻量拐点预瞄；基本朝准后才前进，避免近距离围绕目标画圆
- 直线段疾跑，明显转弯、接近交互目标和跳台阶时自动降为步行
- 种植、收获、补水、浇水和箱子交互会渐进对准目标，不再瞬间跳转视角
- 浇水一轮 = 拿插件洒水壶去水源普通右键装水 → 走到悬浮虚拟浇水器按住 Shift 右键加水
- 上次成功浇水时间持久化到 `autofarm.json`，重启不会重复立即浇水；整轮没有成功交互时不更新时间，5 分钟后重试
- 饥饿值低于 14 时自动吃到 18；背包没食物则去食物箱拿，低于疾跑最低值且拿不到食物时停机
- 没学过成熟特征的作物只种不收（会提示一次）
- 推荐收获方式 `/farm harvestmode use`（默认）：有对应种子时拿种子右键，插件一次完成收获和原地复种；种子耗尽时当前作物立即退回左键收获，不阻塞收割，空地之后再取种子补种
- `/farm harvestmode break` 保留为其他服务器的兼容模式：左键挖掉后再单独补种
- 每个 zone 只有在“成熟率达到门槛”时才加入收获（门槛 `/farm ratio <1-100>` 可配置，默认 50%），空耕地不计入分母
- 所有达标的 zone 加入待处理队列，但严格逐个 zone 收获，不会跨区选择下一株
- 进入 zone 时从离玩家最近的角开始，沿区域较长边按蛇形顺序连续种植/收获；蛇形完成后刷新扫描，并用原来的最近目标策略做一次遗漏兜底
- 当前收获 zone 会先沿蛇形路线收完全部成熟作物，再统一沿蛇形路线补种空地；左键收获产生空地不会中途打断收割
- 种子箱为空时仅该作物进入5分钟冷却并左键回退，不阻塞当前区完成
- 一个 zone 的收获或种植完成后，立即只扫描并拾取该 zone 边界内的掉落物，拾取完成才切换下一个 zone
- 区域拾取范围为 zone 六个方向各外扩一格；会报告检测到的 ItemEntity 数量，远处使用 A*，进入1.2格后关闭疾跑并锁定方向直线穿过物品
- 单个实体接近失败3次只会在当前轮暂时跳过，结束前仍存活会强制重新加入；区域连续4次间隔复扫均为0才确认拾取完成
- 走不到/收不动的地块拉黑 1 分钟后重试；种子箱空 5 分钟后重试；作物箱全满停机

### /farm 命令一览

| 命令 | 作用 |
|---|---|
| `/farm pos1` / `pos2` | 选择下一个小区域的两个角 |
| `/farm zone add <作物>` / `list` / `remove <n>` | 小区域管理（用当前选区） |
| `/farm crop add <作物>`（手持种子） / `list` / `remove` | 作物种子定义 |
| `/farm learn <作物>` / `unlearn <作物>` | 学习/清空成熟特征（准星对准成熟作物） |
| `/farm bindseed <作物>` | 绑定该作物的种子箱 |
| `/farm bindcrop` / `unbindcrop` | 作物存放箱（可多个） |
| `/farm bindwaterer` / `unbindwaterer` | 悬浮虚拟浇水器（可多个） |
| `/farm bindcan` / `unbindcan` | 手持插件洒水壶绑定 / 解绑 |
| `/farm bindwater` | 洒水壶装水点（对准水面） |
| `/farm interval <分钟>` / `canuses <n>` | 浇水间隔 / 每浇水器使用壶数 |
| `/farm bindfood` / `unbindfood` | 手持食物绑定 / 解绑食物 |
| `/farm bindfoodchest` / `unbindfoodchest` | 绑定 / 解绑食物箱 |
| `/farm harvestmode break\|use` | 左键挖，或拿对应种子右键自动收获复种 |
| `/farm speed normal\|medium\|fast` | 速度模式：正常 / 收菜不停步+指针加速对准（快且像人）/ 不停步不对准（最快最机械）；`/farm fast` 保留为 normal↔fast 互切 |
| `/farm info` | dump 准星方块或虚拟实体信息（存 log） |
| `/farm start / stop / status` | 开始/停止/状态（快捷键 K） |

挖矿和种地不能同时运行（互斥）。

## 定时存物 Stash（/stash）

独立于挖矿/种地的小功能：每隔 N 分钟自动走到绑定箱子，把**主背包（除按 E 打开后最上排第一格）**的物品全部存进去；**快捷栏永不存入**。存完自动走回出发位置、转回出发时的朝向，并切回 1 号快捷栏继续计时。

1. 准星对准箱子执行 `/stash bind`（可绑多个，满了自动换下一个）
2. `/stash interval <分钟>` 设置间隔（默认 30）
3. `/stash start` 开启（`/stash now` 立即存一次、`/stash stop` 关闭、`/stash status` 查看倒计时）

| 命令 | 作用 |
|---|---|
| `/stash bind` / `unbind` / `chests` | 绑定/解绑/列出存物箱（准星对准箱子） |
| `/stash interval <分钟>` | 每隔多少分钟存一次（1~1440，默认 30） |
| `/stash bindfood` / `unbindfood` | 绑定/解绑食物箱：饥饿值低于 14 自动吃包里的食物，没食物自动走去食物箱拿（首次取出自动记录食物 id），吃完/拿完走回原位 |
| `/stash now` | 立即执行一轮存物（需已 start） |
| `/stash start / stop / status` | 开启 / 关闭 / 状态 |

挖矿/种地运行时定时器只推迟不触发（它们各自有存物环节）；存物途中启动挖矿/种地会立即让位。

## 构建

JDK 21+（本机 25 可用）：

```bash
./gradlew build    # 或 ./.tools/gradle-9.6.1/bin/gradle build
```

产物 `build/libs/worldutils-1.0.0.jar`，与 Fabric API 一起放入 mods。

## 注意

- 纯客户端实现（模拟按键/点击），不改服务器。
- 在允许辅助工具的服务器/单人存档使用；公共服务器风险自负。
